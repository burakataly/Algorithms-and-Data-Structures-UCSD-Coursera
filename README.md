# Algorithms and Data Structures Specialization

This repository contains my assignments and certificates from the **"Data Structures and Algorithm Specialization"** by UCSD on Coursera. The courses emphasize practical coding through challenging assignments, requiring solutions that are not only correct but also meet strict time and space complexity requirements. 

The specialization allows the use of any programming language, and I chose **C** to solve the assignments, implementing all the required data structures from scratch. While this made the process more challenging, it was a great learning experience to optimize solutions and meet the assignment criteria without relying on built-in libraries and also be able to see what is happening under the hood.
